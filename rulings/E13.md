**Ruled 2026-09-09 by The Lieutenant at the General's instruction.** Ratifiable or overrulable

**This ruling requires no build in either direction.**

## The question is a false dilemma: "φ in the glyphs" names three different things

| # | claim | where | verdict |
|---|---|---|---|
| 1 | φ **emerges** from the structure — a derivation | implied by treating the target as governing | **RETIRED** (already was) |
| 2 | `OSR ≈ φ` — a **semantic compression** target | `CODEX_AUTOPOIETICUS.tex` def:osr | **stands, and is UNBUILT** |
| 3 | 137.5° golden angle, φ-spirals — **geometric** constraints | same file, Glyphic Body Morphogenesis item 4 | **design, not derivation** |

The measurement and the target were never talking about the same object. Bifurcated, nothing
contradicts anything.

## 1 — φ as derivation: retired, and the white paper already retired it *with its own bound*

`WP.tex:4663–4680` is a `[W]` negative result that refuses to overreach, in its own words:

> *"That it did not render golden ratios or hexagonal packing IS a negative result about **this
> renderer** … **not a disproof of the figures elsewhere**." … "the paper records the difference
> so that a negative measurement IS not mistaken for a denial."*

So the measurement never claimed what E13 credits it with. It retires φ-as-emergent **from
`sigil.la`'s pipeline** and says nothing about the corpus's design target.

### ★ But a stronger argument retires φ-as-derivation outright, and it is the corpus's own

Autopoieticus justifies the target this way: *"This is `φ = 1 + 1/φ` applied to glyphic design:
the glyph contains itself plus the remainder of itself, recursively."*

φ is the fixed point of `x = 1 + 1/x`, equivalently **`x² = x + 1`**.
This system's axiom is `∃(∃) ≡ ∃` — **`x² = x`**, whose fixed points are **0 and 1**.

They are different recurrences. `WP.tex:4667` states the structural half — *"metacursion is
`x² = x`, which carries no two-term recurrence for φ to live in"* — and the consequence is
sharper than "we didn't find it": **the ratio of self-containment in this language is 1, not
1.618.** Which is exactly what `α = 1` already says. **φ was imported from a different
recurrence.** It cannot be derived here, and nothing should be built to make it appear.

## 2 — `OSR ≈ φ`: untouched by the measurement, because it is a different quantity

`OSR = Semantic Load / Glyphic Form`. That is a **meaning-to-form compression ratio**. The
renderer's negative result measured **geometry** — ring radii, packing, angles. It never
measured semantic load, so it cannot bear on OSR at all.

**Measured, 2026-09-09: `OSR` appears in no `.la` and no `.sh` in the repository.** The target
is unbuilt. It therefore stands as a *stated design criterion for the OMP*, not as anything
that governs the sigils we actually generate — because nothing computes it.

**Standing obligation if it is ever built:** OSR must be **reported as a measurement beside a
glyph, never a gate that fails a glyph for missing φ.** A gate that rejects a glyph for an
un-golden ratio is `cob.la:16`'s *impose*, wearing a gate's clothes.

## 3 — 137.5° and φ-spirals: a design choice, and the white paper already said so

> *"Whether a boot screen or a seal carries it IS a design choice, not a derivation."*
> — `WP.tex:4676`

**Ruling: permitted on deliberately authored artwork — seals, boot screens, published figures.
Forbidden as an input to any derivational pipeline, and forbidden as a gate predicate.** No gate
may treat φ-presence as evidence of correctness, in either direction.

`cob.la:16` is the governing method and it is unambiguous:
> *"observe, never impose. 'Does not enact' is a fully legitimate, recorded outcome. The
> geometry is NOT shaped to manufacture the cycle."*

### And it is being honoured in fact, not only in principle

Measured 2026-09-09 across all `*.la` and `*.sh`: **nothing imposes `137.5`, a golden angle,
`1.618`, or a φ-ratio anywhere.** `sigil.la` is integer-cell geometry — `RING(16)(16)(14)(2)`,
integer centre, integer radius, integer thickness. No trigonometry, no floating point, no angle,
exactly as `WP.tex` reports. There is no violation to correct.

## THE RULING, stated plainly

**Neither branch of E13 as posed.** The φ target does **not** govern sigil morphogenesis — it
was never about the rendered geometry, and its own justification rests on a recurrence this
system does not have. And measured φ-absence does **not** retire the OSR criterion — it never
measured it.

- φ **as derivation**: retired. Additionally retired by `x² = x` vs `x² = x + 1`.
- `OSR ≈ φ` **as an OMP design criterion**: stands, unbuilt, and constrained to *measure, never
  gate*.
- **137.5°/φ-spirals**: design, never derivation, never a gate predicate.

**E13 closes with no build in either direction.** Nothing is in violation today.

## Falsifiers

1. A two-term recurrence anywhere in the system's core (`∃(∃) ≡ ∃`, metacursion, κ) in which φ
   is a genuine fixed point. That would revive φ-as-derivation and overturn §1.
2. Any code that computes OSR. That would move §2 from *unbuilt* to live, and the
   measure-never-gate constraint would need enforcing rather than merely stating.
3. Any gate that already treats φ-presence or φ-absence as a pass condition. Searched; none.
