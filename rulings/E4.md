## What the corpus actually specifies — Proof Table 7.2, "The Five Causes"

The design E4 proposes is not invention. It is transcription, and the source is exact:

| # | cause | operator that fails | diagnosed by |
|---|---|---|---|
| 1 | **Category Error (CE)** — concept applied to wrong ontological type | `∂` (type undifferentiated) | **OTT** |
| 2 | **Meta-Category Error (MCE)** — rule across recursion layers unsealed | `δ` (boundary uncrossed) | **ITT** |
| 3 | **Unsealed Recursion** — self-reference without structural fixed point (*the Liar, Russell's set*) | `γ` (compression without fixed point) | **ITT** |
| 4 | **Illicit Truth-Apt Classification** — non-truth-apt treated as truth-valued | `ρ` (recognition mis-fired) | **OTT** |
| 5 | **System Overreach** — evaluation beyond expressive capacity | `𝔄` (integration beyond the system) | → **Horizon** |

Plus two **alignment verdicts** for paradoxes that fail at *no* structural link: **ATT-fail**
(smuggles a premise misaligned with Ω) and **Substantive** (genuinely open).

The exhaustiveness argument is derived rather than enumerated: *"cognition IS the operator chain
`∂ → δ → γ → ρ → 𝔄`, and a paradox IS the chain failing at exactly one link… there is no sixth
cause because there is no sixth operator."*

## THE RULING

### 1. Strike "Tier-4" — RATIFIED
**Verified: zero occurrences of `Tier-4` or `Tier 4` in canonical Codex II, and zero in all five
repo variants.** It has no source. Strike it.

### 2. Split verdict from outcome — RATIFIED, and the reason is sharper than recorded
The corpus's five classifications are **verdicts**: `{OTT-fail, ITT-fail, ATT-fail, Substantive,
Horizon}`. Three of them share one **outcome**. Russell is the red path and proves the enum
cannot carry it: **cause = Unsealed Recursion · operator = `γ` · verdict = ITT-fail · outcome =
Dissolved.** That is *four* facts. A single five-valued enum can express one.

### 3. ⚠ The parallax pre-filter is NOT to be "added" — it is already specified
Canonical Codex II `:2344`, opening the Paradox Collapse Protocol:

> *"One filter precedes the instrument… **Parallax puts one referent, one sign, two vantages ---
> and no gate fails, because nothing is mistyped.** The test costs one move: exchange stations.
> If the contradiction dissolves in the exchange, the Protocol stands down… Run the filter
> first; retype only what survives it."*

This is a **transcription task, not a design decision**, and it arrives with its own red-pathable
predicate — **exchange stations** — which is more than most of our gates have. Build it as
specified; do not redesign it.

### 4. ★ ADDITION — parallax is a fourth OUTCOME, and E4's design has no slot for it
The filter runs **before** the instrument and can end the audit with *"no gate fails, because
nothing is mistyped."* That is **not** `Dissolved` — nothing was retyped, and recording it as
Dissolved would claim a dissolution the Protocol explicitly declined to perform. It is not
Substantive and not Horizon.

**Outcome must be `{Parallax, Dissolved, Substantive, Horizon}` — four, not three.** Collapsing
Parallax into Dissolved would rebuild, in the fix, exactly the conflation this ruling removes.

### 5. ★ ADDITION — `operator` is derivable from `cause`, so it must be a CHECK, not just a field
PT 7.2 item 6 maps them one-to-one: `∂`→CE, `δ`→MCE, `γ`→Unsealed Recursion, `ρ`→Illicit
Classification, `𝔄`→Overreach. Returning `(verdict, cause, operator)` is right **only if
something asserts the pair agrees.** Two names for one fact, unchecked, is the defect this
ruling exists to remove — reintroduced as a return value.

**Return `(outcome, verdict, cause, operator)` with a gate that reds when `operator ≠ chain(cause)`.**

## Build order, and the red path is already written

1. Parallax filter first — it precedes the instrument by specification. Red-path: a dispute that
   **does** dissolve under exchange must return `Parallax` and must **not** reach the instrument.
2. Then the five causes, each with its operator. Red-path per cause.
3. **Russell is the acceptance test**, and it is fully determined by the corpus: `(Dissolved,
   ITT-fail, Unsealed Recursion, γ)`. Anything that cannot emit those four values distinctly has
   not implemented E4.

## Falsifiers

1. A sixth cause. PT 7.2 derives five from five operators — *"no sixth cause because there is no
   sixth operator."* Exhibit one and the exhaustiveness claim, not just this ruling, falls.
2. A `Tier-4` in any canonical codex. Searched all variants; zero.
3. A paradox that survives parallax exchange **and** fails at no structural link **and** is not
   genuinely open. That would need a sixth verdict, and §2 would be wrong about the count.
