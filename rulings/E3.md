# E3 / M50 — RULING: which type system is the language's?

**Ruled 2026-09-09 by The Lieutenant at the General's instruction, after saying I did not think
this one was mine to make.** The General overruled that; recorded because the reversal is part
of the record. Ratifiable or overrulable. **Blocks Seal 2 (M51, proof-carrying glyphs).**

⚠ **First, our register mis-stated the question — the fifth time today.** `ROADMAP-CURRENT`
carried E3 as *"not a ruling but a scope call: in or out of 'complete as envisioned'?"* The
authority (`14-MASTER-LIST.md:276`) says: **"rule which type system is the language's."** Those

## The three are not three type systems. They are three layers.

E3 presupposes a rivalry. Measured, only one of the three was ever a candidate.

### 1. Arrow-arity in `DEPLOY` — the **well-formedness floor**. Built, gated. Retain.
303 `::` signatures across `*.la`; `DECL_ARITY` / `BODY_ARITY` / `INHABITS` wired into
`NC_TYPECHECK`. It answers *"is this term even applicable?"* It is **not a rival** and was never
competing for the title — it is the floor the others stand on. **Keep it exactly as it is.**

### 2. The codex's Ontic Type System — **documentation, not machinery. Retired as a candidate.**
`LINGUA_ADAMICA.tex:5012`: `τ ∈ {Object, Process, Relation, Value, Constraint}`.

**Footprint in code: zero — proven, not assumed.** M50 records "zero occurrences"; my first check
used the wrong five names and returned a zero that was my instrument, not the world. Re-run with
the correct names, exactly one file matched — `asm.la` — and the hit is **`K6C_SLOTSZ`**, a
substring. **Genuinely zero.**

And structurally it could not have been the answer: OTS **assigns a tag**. Seal 2 requires a
**derivation**. A sort discipline cannot produce one. Keep the vocabulary for prose if it is
useful; it is not the type system.

### 3. `TYPE_SYSTEM_SPEC.md` — dependent types over the five modes. **THIS IS THE LANGUAGE'S.**

Three reasons, in order of force:

**(a) It is the only candidate that can carry Seal 2.** `LINGUA_ADAMICA.tex`, the subsection
**immediately after** OTS, requires every glyph to ship *"(a) a type derivation, (b) an
equivalence certificate linking it to its ONF, (c) a reality witness, (d) a version stamp and
migration proof."* Arrow-arity emits no derivation. OTS emits a tag. **Dependent types are
definitionally proof-carrying: the type is the proposition, the term is the proof.** Seal 2 is
not an argument for this choice — it is the *definition* of the requirement, and only one
candidate meets it.

**(b) It is not new machinery, and its central claim verifies.** Its own thesis: *"the type
system is not new machinery bolted on — it is `metadebug.la`'s spec table, read as a type
discipline"* and *"the type-checker already exists: it is `IS_AUTOLOGICAL`."*
**Verified:** `IS_AUTOLOGICAL` is defined at `metadebug.la:180`, appears **in its own spec
table** at `:141` (it checks itself), and is gated at `build.sh:863`.

**(c) Its constructors are the five modes, and E11 already ruled on them today.** All five are
live in the build. And **inhabitation (`value : type`) is `⊂`** — the one mode E11 found the
*lexicon* never exercises. **E3 and E11 meet exactly here:** `⊂` is about to become the
inhabitation relation of the type system, which retires E11's "vocabulary gap" as a non-issue
and gives `⊂` the load it was missing.

## ⚠ A CORRECTION TO THE SPEC, and it changes the scope

`TYPE_SYSTEM_SPEC.md` asserts: *"The nine primitives **already carry** types (`τ_E, τ_P, τ_R,
τ_Q, τ_↻`), so a type system is endogenous to Lingua Adamica, not imported."*

**Measured: no `τ_E` / `TAU_E` / equivalent appears in any `.la`. That premise is unbuilt, and
it is written in the present tense.** The spec is right that the *checker* exists. It is wrong
that the *types* do. Same overclaim-by-tense the corpus makes elsewhere, in the document that is
supposed to fix typing.

## Scope — and "the largest single unbuilt item" is measuring the wrong thing

| | state |
|---|---|
| the checker (`IS_AUTOLOGICAL`) | **built, self-checking, gated** |
| the five constructors (the modes) | **built, all five live** (E11) |
| the well-formedness floor (arrow-arity) | **built, 303 signatures, gated** |
| dependency's prerequisite (native integers) | **built** — the spec names it as *"just added"* |
| τ-tags on the nine primitives | **unbuilt** |
| types as first-class predicates | **unbuilt** |
| dependency | **unbuilt** |

**This is not a from-scratch type system.** It is three additions on top of a checker that
already runs and already checks itself. Calling it *"the largest single unbuilt item"* measured
the **specification's** size, not the **delta**.

**I am not putting a time figure on it.** I have no measurement that would support one, and an
invented estimate is the defect I have spent the day catching in others.

## Build order — and the order is the argument

1. **τ-tags on the nine primitives.** Smallest, and it is the premise the other two assume. It
   is also the item the spec wrongly believes is done.
2. **Types as first-class predicates.** The spec's claim is that `IS_AUTOLOGICAL` already is one
   in effect; making it first-class is exposure, not construction.
3. **Dependency.** Prerequisite already met.
4. **Then M51 / Seal 2 unblocks** — which is the reason for the order, not a bonus at the end.

## THE RULING, stated plainly

**The language's type system is dependent types over the five modes, as specified in
`TYPE_SYSTEM_SPEC.md`.** Arrow-arity is retained beneath it as the well-formedness layer, not as
a rival. **OTS is retired as a candidate** — documentation, zero footprint, and structurally
incapable of Seal 2. **The three were never in competition; they were a floor, a vocabulary, and
a proposition layer, sharing one name.**

## Falsifiers

1. **Any OTS machinery in code.** Searched with all five correct type names; the sole hit is
   `SLOTSZ`. Exhibit one and §2 is wrong.
2. **A way for arrow-arity to emit a type derivation.** If one exists, candidate 3 is not
   uniquely required and Seal 2 could ride the built layer.
3. **`τ_E`/`τ_P`/`τ_R`/`τ_Q`/`τ_↻` existing anywhere.** That moves build-order item 1 to done and
   the spec's premise from wrong to right.
