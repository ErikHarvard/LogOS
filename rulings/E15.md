# E15 — RULING: does *"the truth tables are not stipulated"* stand as `[W]`?

**Opened 2026-09-09 by The Lieutenant while ruling E12. Ruled the same day at the General's
instruction.** Ratifiable or overrulable by the General.

**The claim** — Codex II (*Logos & Paradox*) Proof Table 4.1 item 6:

> *"All five connectives are derived from the Three Laws. The truth tables are not stipulated —
> they are the Laws instantiated at propositional resolution."*

---

## First: the claim is two claims, and one of them was never made

- **E15a — the truth TABLES follow from the Laws.** Codex II Table 4.1 items 1–5 give a real
  argument for each: `∧` because *both must be themselves for the conjunction to be itself*;
  `∨` because *the middle is excluded*; `→` false only on true→false because *recognition that
  leads from truth to falsehood is failed recognition*. This is substantive and arguable.
- **E15b — the ENCODINGS follow from the Laws.** Never claimed, and it cannot be true: many
  lambda terms compute one table. **The corpus proves it itself** — `NOT` appears in ~80
  modules in five structurally distinct forms, all computing the same table.

⚠ **My own objection when I opened E15 — "`NOT` is a stipulated Church boolean" — was aimed at
E15b.** To that extent it missed, and the record should say so.

---

## Ruling on E15a: **`[A]`, not `[W]`** — and not for the reason I first gave

The standard in this project is not *is the argument good*. It is **did a gate run that could
have gone RED**. Three measurements, in increasing severity:

**1. The expectations are transcribed, not derived.** `metalogic_spec.la:257–271`:
```
CONS(E("AND")(":: a -> b -> c")(SRC_AND)(AND)(
      T2L(TC(la g. g(TRUE)(TRUE)("y")("n"))("y"))
         (TC(la g. g(TRUE)(FALSE)("y")("n"))("n"))))
```
`"y"` and `"n"` are literals typed by the same hand as the implementation. This witnesses *the
code does what the author wrote twice*, not *the Law forces the table*. Our own sealed class:
**a pasted expectation never reds for its own bug.**

**2. Coverage is 2 of 4 rows per binary connective**, and the untested half is systematic:
`AND` is **never** evaluated with a false first argument; `OR` is **never** evaluated with a
true one. Each connective's tests exercise only one branch of its own selector.

**3. ★ The gate does not test what it deploys.** `AND` is **imported** from `specpipe.la:64`;
`SRC_AND` (`:157`) is a **separate string literal** that is written into `metalogic.la`. The
entry `E("AND")(sig)(SRC_AND)(AND)(tests)` carries both — and **nothing checks they denote the
same function.**

### Proven by mutation, not argued

Setting `SRC_NOT = "la b. b(TRUE)(TRUE)"` (negation destroyed — `NOT(anything) = TRUE`) and
`SRC_AND = "la a. la b. a(b)(TRUE)"` (conjunction destroyed), then running the spec:

```
  NOT: PASS
  AND: PASS
  OR: PASS
  module VERIFIED
```

and what landed in the deployed module:

```
metalogic.la:7  glyph NOT = la b. b(TRUE)(TRUE)
metalogic.la:9  glyph AND = la a. la b. a(b)(TRUE)
```

*(`metalogic.la` was copied before the run and restored after; verified byte-identical to HEAD.
A verification must not write to what it measures.)*

**Verdict: `[A]`.** There is no gate that would go RED if the tables did not follow from the
Laws — and, more sharply, **no gate that would go RED if the deployed connectives were
destroyed.**

---

## The path to `[W]`, and the trap in it

Per connective: compute the expected row-set **from an independent statement of the governing
Law**, run **all four rows**, and execute the **deployed `metalogic.la`** rather than the
spec-local imported glyph.

⚠ **The obvious version of this gate witnesses nothing.** Comparing output against a hardcoded
table is a transcription of the implementation — `expected-values-derived-not-captured`, the
same defect this ruling is about, rebuilt as its own fix. Red-path it twice: once by perturbing
a row of the **law-derived expectation**, once by perturbing `SRC_*`.

## What IS witnessed, and must not be lost in this ruling

The three laws genuinely red-path. `metalogic_spec.la:241–248` gives each law both a TRUE and a
FALSE witness — including *"the first real FALSE the law of identity has ever produced"*. The
module is regenerated from its spec every build, so it cannot drift by hand-edit. Both real,
both gated at `build.sh:2520–2552`.

## ★ The finding under the finding

`metalogic_spec.la:28–37` already states its own bound:

> *"What is witnessed is LOCAL AUTOLOGICAL CLOSURE — the same bound canon.la's NORMK and
> denote.la's κ-agreement already carry, not a frame-independent metatheorem."*

**The spec states the bound the prose overclaims.** E15 is not the corpus being wrong. It is
**two registers under one name** — the spec's careful witness and the codex's expansive one —
which is the identical shape as E12. Bifurcated, both are true and neither needs retracting.

## ⛔ SEPARATELY, AND THIS IS NOT A DOCUMENTATION MATTER

The deployed-vs-tested hole is a **live defect in a gate the build runs today**, independent of
this ruling. It is dispatched to the board, not filed here.

## Falsifiers

1. A gate elsewhere that executes the deployed `metalogic.la` and exercises its connectives.
   If one exists, measurement 3 is wrong. I found none.
2. A derivation, anywhere in the corpus or code, that produces a connective's table **from** a
   law rather than asserting their correspondence. If one exists, E15a is `[W]` and this ruling
   is overturned.
